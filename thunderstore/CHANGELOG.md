# Changelog

## 0.1.0

- Initial public release of configurable automatic pickup for mined resources.
- Add a separate in-game F10 ore selection window with icons, search and per-resource controls.
- Exclude Stone by default on the first two maps; automatically collect other discovered ores.
- Add adjustable pickup radius, shortcut remapping and persistent per-profile settings.
- Show colored pickup notifications based on confirmed inventory count increases.
- Attempt to prevent automatic recollection of locally dropped ore stacks; multiplayer-origin drop protection remains limited.
